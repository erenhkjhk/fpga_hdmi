# 缩放与淡入淡出流水线优化

完成日期：2026-10-25（综合及首批仿真执行于2026-10-24）。基准提交：`f8bf19e`（第一次综合），分支 `extension-1-4-prep`。本轮按用户要求只修改两处运算及相应测试、文档，运行 ModelSim Intel FPGA Starter Edition 2020.1 功能回归和 TD 6.2.168116 综合核查，**没有运行布局布线、bitgen 或烧录**。旧 `syn_1` / `phy_1` / `best_result` 保持不动。

## RTL 行为

### 双线性缩放（50 MHz）

`bilinear_scaler.v` 保持端点对齐、精确商/余数地址、Q8权重、邻点夹取、水平Q8精度和纵向四舍五入规则。

- 原来的组合 `rem*256/639`、`rem*256/479` 改成初始化后8拍二进制小数计算，每拍只有11位比较/减法；得到的权重仍是相同的向下取整值，不做近似。
- 水平上、水平下、垂直三个运算仍在RGB三个通道间复用一个有符号乘法器。每次运算分为操作数/基值寄存 → 乘积寄存 → 累加写回，`blend_kind` 保持写回目标。
- `SEND` 只在三个通道均完成后出现，背压期间数据保持；取消/复位丢弃当前作业，重启先初始化权重，旧乘积不能形成有效输出。
- 相对初版每个目标像素增加27拍计算预算，50 MHz下整帧约增加0.166秒后台加载时间。显示仍为25 MHz像素、125 MHz串行，自动停留和转场帧数保持原设计。

### 淡入淡出（150 MHz）

保持原公式 `((256-alpha)*old + alpha*new + 128) >> 8`，Alpha范围0–256、每帧步进4，正负差值及Alpha=256均保留足够位宽。

| 阶段 | 数据和控制 |
|---|---|
| S0 | 同步旧块RAM读取，与新像素、Alpha、转场标记对齐 |
| S1 | 三路有符号RGB差值寄存，同时延迟旧像素基值、直通像素和模式 |
| S2 | 三路乘积寄存，继续延迟基值、直通像素和模式 |
| S3 | 加入 `old*256+128`，截取原结果位段；无转场时选择延迟后的完整32位直通像素 |
| 下一沿 | 视频FIFO按对应valid写入 |

返回可含空拍，valid逐级传播；流水线填满后仍可每拍处理一个像素。`R_DRAIN` 保留64字返回和20拍静默条件，并增加全部混合valid均为空的 `!blend_busy` 条件，避免释放旧块或新帧复位时遗留输出。fault与系统复位阻断后续写入。

没有新增模块文件或端口，`project1.al` 与 `rtl/sources.f` 无需变更。没有修改RAM/ROM/FIFO/PLL生成文件、MIF、字模或Logo，也没有修改ADC/SDC、降低频率或增加时序例外。
