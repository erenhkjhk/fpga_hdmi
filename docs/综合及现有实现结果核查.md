## 告警评估

- `PHY-5079`：`clk_sdram_180` 的 `u_sdram/u_controller/SDRAM_CLK` 使用一条局部布线，是重点待核查项。不能未经器件接口核对就断言必须插入 BUFG，也不能忽略它与 SDRAM 路径 skew 的关联。
- `PHY-7002`：`u_sdram/u_sdram` 初始位置 `(12,12)` 不合法，工具将在布局中移动。现有顶层 ADC 没有该实例位置约束；应复核合封 SDRAM 原语映射和合法位置，不能随意补一个位置值。
- `PHY-5089`：13 条异常时序路径因 skew > 1000 ps 或 hold slack < −1000 ps 被跳过相关布线处理。后续可加载现有 `pr.db` 用工具建议的 `report_abnormal_timing_target` 定位，不能以 bitgen 成功替代处理。
- `SYN-5011/5025`：包括厂商 RAM/FIFO 未驱动备用引脚，以及 Map Macro 阶段部分按键、拨码、SDRAM 读数据寄存器 `clk` 未驱动消息。物理 I/O 表显示按键/拨码已打包到 IREG；这些消息可能与 I/O 打包有关，但仅凭日志不能把所有条目判为无害，后续应检查最终网表的真实时钟连接。
- 厂商文件还有未命名 generate、常量位宽、未连接端口、非 DFF 初值被忽略等告警。本次保留原始 IP，不将“综合结束”描述成“无告警通过”。

后续优先处理缩放与淡入淡出的长组合路径，再核对 SDRAM 时钟/接口映射及 CDC、复位例外。保留 25/125 MHz HDMI、150 MHz 及 180° SDRAM 时钟要求。若确需新增或修改 IP，先列出参数，由用户在 TD 手动生成。
